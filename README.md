# 🛡️ 산업안전보건 통합점검 & 실시간 모니터링 대시보드

산업안전보건법 및 중대재해처벌법 대응을 위한 Python 기반 작업장 안전점검 관리 및 실시간 대시보드 웹 애플리케이션입니다.

---

## 🌟 주요 기능

1. **📊 종합 현황 대시보드 (Real-time Analytics)**
   - 안전 적합률, 주의/개선권고, 긴급 부적합(미조치) 등 핵심 KPI 요약
   - 구역별 점검 결과 분포 (양호 vs 주의 vs 불량 누적 차트)
   - 안전 분야별 점검 비중 (기계방호, 화재/소방, 전기안전, 유해물질 등)
   - 위험도(Risk Level: 낮음/보통/높음/치명적) 등급 분석
   - 시계열 일별 점검 추이 및 최근 점검 이력 요약

2. **✍️ 실시간 안전점검 일지 등록**
   - 사업장, 점검 상세 구역, 안전 분야, 점검 항목별 현장 점검표 작성
   - 양호/주의/불량 결과 판정 및 4단계 위험도 평가
   - 시정 조치 계획, 조치 예정 기한, 담당자 지정 지원
   - 저장 즉시 SQLite DB에 기록되고 대시보드에 실시간 반영

3. **🛠️ 위해·위험 요인 시정조치 관리 (Action Items)**
   - 주의 및 불량 항목만 모아놓은 전용 조치 현황 추적
   - 현장 조치 상태(미조치 ➔ 조치중 ➔ 완료) 즉시 변경 및 보고서 보완
   - 엑셀 및 CSV 다운로드 기능 제공 (내부 감사/보고서 활용)

4. **📖 안전 수칙 & 가이드**
   - 중대재해 예방 3대 핵심 수칙 및 정기 점검 주기 권장 가이드

---

## 🛠️ 기술 스택
- **Language**: Python 3.13
- **Web UI & Dashboard**: Streamlit
- **Data Visualization**: Plotly, Pandas
- **Database**: SQLite3 (설치 불필요, 파일 기반 자동 생성)

---

## 🚀 실행 방법

### 1. 가상환경 활성화 및 패키지 설치 (최초 1회)
```bash
python -m venv .venv
.\.venv\Scripts\pip.exe install -r requirements.txt
```

### 2. 대시보드 실행
```bash
.\.venv\Scripts\streamlit.exe run app.py
```
브라우저에서 `http://localhost:8501` 주소로 대시보드가 자동으로 열립니다.

또는 간편하게 `run.bat` 파일을 더블 클릭하여 실행할 수 있습니다.
